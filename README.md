# Калькулятор стоимости крашеных фасадов (МДФ / шпон)

Расчёт стоимости фасадов в стилистике сайта **«Среда»** (mebelart.net).
Один самодостаточный файл `index.html` — работает офлайн, без установки и интернета.
Откройте `index.html` в браузере (Chrome / Edge / Safari).

## Возможности

- **Имя / заказчик** в шапке — при вводе документ автоматически сохраняется
  в браузере под этим именем (новое имя = новый файл). Список сохранённых
  расчётов — в выпадающем «Открыть расчёт…».
- **Несколько видов фасадов** в одном документе: кнопка «＋ Добавить вид
  фасада» создаёт новый блок-табличку со своим наименованием, типом отделки
  и списком деталей. Каждый блок можно удалить.
- **Автоподстановка наименования детали**: в колонку «Наименование» каждой
  детали автоматически подтягивается «наименование фасада · тип отделки».
  При необходимости текст в ячейке можно перезаписать вручную (очистка ячейки
  возвращает автоматическое значение).
- **Таблица позиций** с автонумерацией: наименование, высота, ширина,
  толщина (мм) и количество (шт).
- **Автоматический расчёт цены** из прайса.
- **Галочка «обратка»** (покраска с обратной стороны) у каждой детали: при
  включении строка становится **жирной**, а к цене добавляется стоимость
  покраски обратной стороны.
- **Навигация стрелками** ↑ ↓ ← → и Enter, как в Excel. Новая строка
  добавляется автоматически при заполнении последней.
- **Печать / PDF** — системный диалог печати (в нём же «Сохранить как PDF»).
- **Подвал документа**: данные заказчика (из имени), строка «С размерами
  согласен» и место для подписи.
- **Экспорт** расчёта в JSON-файл.

## Прайс

Прайс редактируется прямо в интерфейсе (блок «Прайс-лист»); изменения
сохраняются в браузере. Кнопка «Сбросить прайс» возвращает значения ниже.

### Изготовление (МДФ + покраска) — ₽/м² по толщине

| Тип отделки | 16 мм | 19 мм | 22 мм |
|---|---:|---:|---:|
| Мыло (мат) | 6 445 | 6 825 | 7 254 |
| Фреза (мат) | 9 295 | 9 675 | 10 001 |
| Глянец | 8 853 | 9 233 | 9 663 |
| Фрезерованный глянец | 11 703 | 12 083 | 12 513 |

(из присланного Excel, столбцы «наименование / цена м²»)

### Покраска материала заказчика — ₽/м² (фикс., без привязки к толщине)

| Тип отделки | ₽/м² | Обратка по цене |
|---|---:|---|
| Покраска заказчика · фреза | 6 580 | краски |
| Покраска заказчика · мыло | 4 500 | краски |
| Покраска заказчика · глянец | 7 280 | краски |
| Шпон файнлайн | 8 600 | шпона |
| Шпон натуральный | 11 600 | шпона |
| Шпон рамка | 13 400 | шпона |

### Параметры расчёта

- **Обратка · краска** — 4 500 ₽/м² (добавляется по галочке для крашеных отделок)
- **Обратка · шпон** — 5 500 ₽/м² (для шпонированных отделок)
- **Мин. площадь** — 0,7 м² по всему списку деталей каждого вида фасада
- **Наценка** — 0 % (можно задать общий процент к прайсу)

## Формула

```
Сумма детали   = площадь (В×Ш, м²) × (цена ₽/м² + обратка, если отмечена) × кол-во
Сумма по виду  = Σ по деталям, но не меньше «мин. площадь × цена отделки»
Итого          = Σ по всем видам фасадов
```

Цена ₽/м² для «Изготовления» берётся по толщине детали; для «Покраски
заказчика» — фиксированная. Обратка для крашеных отделок — по цене краски,
для шпона — по цене шпона.

## Технические детали

- Автосохранение и прайс хранятся в `localStorage` браузера (данные не
  покидают компьютер). Для переноса на другой ПК используйте «Экспорт».
